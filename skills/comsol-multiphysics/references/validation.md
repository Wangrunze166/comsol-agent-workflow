# 验证与报告

制定验证方案时使用项目根目录的 `templates/verification-plan.template.md`，明确每项额外计算的验收阈值与审批范围。

## 分层结论

| 层级 | 所需证据 | 不能推导出的结论 |
|---|---|---|
| 静态检查通过 | 清单、单位、参数范围与计划检查 | COMSOL API 或真实模型已运行 |
| 接口编译通过 | 本机编译日志与退出码 | 许可可用、求解收敛或结果正确 |
| 求解完成 | 完成记录、所需扫描/时刻、有效输出 | 网格独立或物理正确 |
| 数值复现通过 | 同坐标、同单位、既定容差的逐点比较 | 与实验吻合或适用于新工况 |
| 工程验证通过 | 约定的守恒、独立性、基准或实验指标 | 超出已验证范围的适用性 |

比较前确认模型版本、参数、表达式、单位、数据集和采样坐标一致。坐标重复、缺失点、非有限值或列含义不一致时停止比较；不得静默截断或补零。插值仅在预先规定的方法与误差说明下使用。

## 验证计划

验证阈值在求解前与用户确认，按关键输出分别定义。项目可以明确某项不适用或暂未完成，但报告必须保留该状态。

- **守恒：** 按模型边界定义质量、能量、电荷或力平衡。瞬态能量平衡包含储能项，热电模块需分清电功率、冷/热端热流和内部约定符号。
- **网格独立性：** 使用有意义的加密序列，记录单元数、自由度、质量与关键输出相对变化。只比较一对网格不足以普遍证明渐近收敛；局部峰值另看奇异性和提取位置。
- **时间与容差：** 比较更小最大时间步/更严格容差下的瞬态关键指标。输出采样间隔不同于内部求解步长。
- **参数与假设：** 对影响结论的材料、接触、对流、边界、控制参数作经批准的敏感性分析，说明不确定性。
- **独立基准：** 优先解析解、独立数值方法、可靠试验或官方保存解；说明每类比较能证明的范围。

## 热电 PI 案例的解释边界

稳态扫描参考 0.5–3.5 A 共 7 点，瞬态参考 0–60 min、每 2 min 输出，共 31 点。每 2 min 的输出不能确定采样点之间的精确峰值或调节时间。

`comp1.dom1` 是器件平均温度；`comp1.lts.TEM1.P` 沿用官方热流率定义；`comp1.lts.TEM1.DT` 是模块温差。模块热流率不能直接改称器件发热功率或单独的冷端制冷量。官方说明中的近似数值与下载模型保存解应分开引用。

## 可复现交付

每次运行保留：案例配置和原始输入哈希、依赖清单、COMSOL/执行器版本、生成驱动、执行计划、两阶段审批、日志与状态、求解后 MPH、原始 CSV、比较结果和报告。报告列出已执行与未执行的验证、异常、限制和复算方式。

自动报告先汇总可证实的机器记录；工程结论由证据与已确认标准形成。新报告不能把旧项目成功记录转写为新执行器的实测通过。

对外发布只包含可再分发的代码、模板、公开元数据和明确标为合成的演示数据。客户模型、CAD、材料数据、许可证信息、审批身份、运行日志和绝对路径留在私有交付中。
