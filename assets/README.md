# Original project graphics

- `hero.svg`: an exploded thermal-system schematic used as the project cover.
- `workflow.svg`: the review, approval, execution and evidence path.
- `thermoelectric-case.svg`: the staged-flow and PI-control reference-case concept.

These editable SVGs were authored for this repository and are covered by its MIT license. They are conceptual illustrations, not screenshots, reconstructed CAD, finite-element meshes or computed simulation fields. Colors distinguish components and workflow roles. No third-party figure, logo or trademark graphic was copied.

Presentation references and their role are listed in `docs/presentation-references.md` at the repository root.
